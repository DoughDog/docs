---
title: "Subscription Attributes"
description: "Carry cart-entered metadata through checkout onto the subscription"
---

Sometimes a customer enters a value at the cart that should stick to their subscription — a birthday, or where they subscribed from (product page, mini-cart, a flow). Subscription attributes let that metadata ride a cart line-item property through Shopify checkout and onto the subscription.

## How it works

Attach a line-item property named `__dough_attr_<key>` to a subscription line in the cart. During checkout processing, Dough Dog strips the `__dough_attr_` prefix off any matching property and captures the value on the resulting subscription under `<key>`.

A few things to know:

- **Per line, per subscription.** Attributes are read from the subscription's own line item, so each subscription gets its own values.
- **Stored as strings.** Everything arrives from Shopify as text and is stored raw.
- **Prefixed properties only.** Properties without the `__dough_attr_` prefix are ignored.

## Adding it to the cart

Attach the property alongside the variant `id` and `selling_plan` when you add the subscription line. You can send multiple `__dough_attr_*` properties on the same line — each is captured as its own key.

```js
fetch('/cart/add.js', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    items: [
      {
        id: 1234567890,          // variant ID
        quantity: 1,
        selling_plan: 2222222222, // numeric selling plan ID
        properties: {
          __dough_attr_birthday: '1990-04-21',
          __dough_attr_source: 'pdp'
        }
      }
    ]
  })
});
```

<Note>
Attributes are captured at checkout. Editing them later from the customer portal or by support is not part of this flow.
</Note>
